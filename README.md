・使用データについて  
教師データとしてURMPという、ロチェスター大学が提供している楽曲データを使用しており、この音源ではJupiterなどの楽曲を演奏しています。URMPには2楽器混合演奏と単体楽器演奏の２種類のファイルがあり、単体楽器演奏を教師データ、2楽器混合演奏をテストデータとして使いました。(2楽器混合演奏はorchestra.pyでのみ使用)
単体楽器演奏のデータをチェロ、フルート、ホルン、オーボエ、ヴァイオリンごとに分けて分類したものが../wavlist/URMP_Sepに入っています。

・orchestra_live.pyのコードについて  
学習方法：  
先頭から15秒までを読み込み、2秒ずつに分割して。それぞれのRMS(音量みたいなもの)が、計測した中で最大のRMSから5%未満の部分は除外する。残った区間を32個の数値に変換し、それを特徴量とする。

特徴量  
音量の時間変化　5項目  
周波数の重心　1項目  
MFCC(音色を計測する)の平均　26項目

サポートベクターマシンで学習する。現在の設定はRBFカーネル、C=3.0、gamma="scale"になっています。
