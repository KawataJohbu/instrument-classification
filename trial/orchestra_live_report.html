Orchestra Live Classification

trial/orchestra_live.py は、教師データ wavlist/URMP_Sep で学習した分類器を使い、 PCマイクから入った音を数秒ごとに録音して、5種類の楽器らしさをリアルタイムに表示するコードです。

Input: microphone Feature: MFCC + envelope Model: scikit-learn SVC Output: 5-class score

Current Setup

Target classes5
Live window3.0s
Sample rate44.1k
Default threshold20

Processing Flow

Training Data Used

ライブ判定でも、学習に使うデータは通常の orchestra.py と同じです。 起動時に wavlist/URMP_Sep を読み込み、短いセグメントに分けて特徴量を作ります。

violin
30
flute
18
cello
11
oboe
6
horn

データ数はクラスごとに偏りがあります。特に horn と oboe は少ないため、リアルタイム判定で不安定になりやすいです。

Feature Vector

1回の録音音声から、合計32個の数値を作って分類器に渡します。 MFCCは音色の違いを見るための中心的な特徴量です。

Feature groupCountMeaning
Envelope5attack, sustain, tail, peak/mean, time centroid
Spectral centroid1音の明るさ・高周波寄りかどうか
MFCC mean13音色の平均的な形
MFCC std13音色が時間内でどれくらい変化するか

Live Loop

1. Train起動時に教師データからSVCモデルを作ります。
2. Recordマイクからデフォルト3秒間録音します。
3. Skip SilenceRMSが低すぎる場合は判定せず次へ進みます。
4. Predict録音した音を特徴量化し、5楽器のスコアを表示します。

Commands

まずマイク一覧を確認します。

.\.venv\Scripts\python.exe .\trial\orchestra_live.py --list-devices

1回だけ録音して判定する場合です。最初の動作確認に向いています。

.\.venv\Scripts\python.exe .\trial\orchestra_live.py --once

継続してリアルタイム判定する場合です。止めるときは Ctrl+C を押します。

.\.venv\Scripts\python.exe .\trial\orchestra_live.py

特定の入力デバイスを使う場合です。

.\.venv\Scripts\python.exe .\trial\orchestra_live.py --device 1

Important Notes

PointMeaning
リアルタイムといっても完全な瞬間判定ではない デフォルトでは3秒録音してから判定するため、約3秒ごとに結果が更新されます。
マイク音は教師データと条件が違う 部屋の反響、PCスピーカー、環境ノイズの影響で、WAVテストより精度が下がることがあります。
--min-rms が小さすぎるとノイズも判定する 静かな部屋で勝手に判定される場合は --min-rms 500 のように上げます。
--window-seconds は精度と反応速度のトレードオフ 長いほど安定しやすく、短いほど反応は速いですが不安定になりやすいです。
